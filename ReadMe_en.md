# 🕹️ Game Collection — Multi-language Projects

This repository contains a collection of classic games implemented in various programming languages.  
Each project explores different concepts such as terminal interaction, graphical interfaces, algorithms, and even esoteric languages.

---

## 📚 Games Included

| Game                  | Language        | Interface   |
| --------------------- | --------------- | ----------- |
| Battleship            | C               | Terminal    |
| Minesweeper           | Java            | Terminal    |
| Conway’s Game of Life | OCaml           | Terminal    |
| Gomoku                | C++             | Terminal    |
| Nim                   | C               | Terminal    |
| Repeat                | Lua / LÖVE      | Graphique   |
| Snake                 | Python / Pygame | Graphique   |
| Sokoban               | C / ncurses     | Terminal    |
| Sudoku                | C#              | Terminal    |
| Sliding Puzzle        | C#              | Terminal    |
| Tic-Tac-Toe ×3        | Brainfuck, Asciidots, Whenever | Terminal    |
| Connect 4             | Ruby            | Terminal + LAN |
| Blue-jam (work in progress) | Unity/C#  | Graphique   |

## 🧰 **Technologies used**

* **C**: ncurses, Unix signals
* **Java**: I/O, keyboard management
* **Python**: Pygame
* **Lua**: LÖVE framework
* **Ruby**: TCP sockets for LAN mode

Compilation of games -- old reworked study projects or personal projects.
